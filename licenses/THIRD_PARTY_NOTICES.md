# Third-party notices

The `bin/libcurl-x64.dll` file comes from the official curl-for-win bundle. The
bundle statically links the components listed below. License and notice files
are copied from the archive's `dep/` directory and retain their upstream
component paths under `licenses/third_party/`.

| Component | Preserved file |
| --- | --- |
| brotli | `brotli/LICENSE.txt` |
| certdata | `certdata/LICENSE.url` |
| libpsl | `libpsl/COPYING.txt` |
| LibreSSL | `libressl/COPYING.txt` |
| libssh2 | `libssh2/COPYING.txt` |
| nghttp2 | `nghttp2/COPYING.txt` |
| nghttp3 | `nghttp3/COPYING.txt` |
| ngtcp2 | `ngtcp2/COPYING.txt` |
| Public Suffix List | `psl/LICENSE.txt` |
| trurl | `trurl/COPYING.txt` |
| zlib-ng | `zlibng/LICENSE.md` |
| zstd | `zstd/LICENSE.txt` |

The curl project license is preserved separately as `COPYING.txt` at the
repository root. The upstream archive and its SHA256 are recorded in the root
README.
